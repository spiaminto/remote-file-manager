# 코드 컨벤션

> 작성일: 26-11-27\
> 최종 수정일: 26-11-27

`src/` 아래의 코드를 작성하거나 리뷰하기 전에 Read 도구로 끝까지 읽는다. 작성하기 전에 읽었는지는 훅(`.claude/hooks/require-conventions.cjs`)이 확인한다.

반드시 지켜야 하는 컨벤션과, 에이전트의 기본 동작이나 기존 코드의 스타일과 다른 컨벤션을 모은다. 기존 코드를 따라 작성하면 지켜지는 관례는 적지 않는다. 항목마다 규칙과 정한 날을 적고, 기존 코드를 어떻게 할지가 정해진 항목은 그것도 적는다. 언어와 구성이 정해지면 그 언어의 항목을 더한다.

- 소스 파일은 Edit·Write 도구로 고친다. 이 도구로 고치면 훅이 수정 전에 이 문서를 읽었는지 확인해 막을 수 있다. 셸 명령으로 고치면 훅은 수정이 끝난 뒤에야 확인하므로, 컨벤션에 어긋난 코드가 먼저 파일에 남는다.
- 코드를 리뷰할 때는 바뀐 코드를 아래 항목마다 대조하고, 어긋난 곳을 항목의 이름과 함께 지적한다.

## 주석

- **규칙:** 밖으로 공개하는 타입과 함수(export, public)에는 그 언어의 문서 주석(JSDoc, docstring, Javadoc 등)을 단다. 첫 문장은 그 타입이나 함수의 역할 한 줄이다. 줄 주석에는 의도, 이유, 도메인 규칙을 적고, 코드를 읽으면 바로 아는 것에는 줄 주석을 달지 않는다.
- **기존 코드:** 기존 주석은 지우지 않는다.
